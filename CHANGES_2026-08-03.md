# SAPAS Update — 2026-08-03

This update implements the requested Add Employee validation, Analytics layout cleanup, Workforce Policy Center cleanup, August 1–4 demonstration attendance/overtime data, and realistic 2026 holidays.

## Add Employee

- Email format is checked while the administrator types.
- Password requirements update while typing and mirror the server rules:
  - minimum 10 characters;
  - at least one letter;
  - at least one number;
  - not one of the blocked common passwords.
- Confirm Password reports a mismatch immediately.
- The server remains authoritative on submit.
- Phone numbers have no format restriction. Only the existing 50-character storage safety limit remains.

## Analytics

- Removed the oversized period hero and unused visual space.
- Average Attendance, Attendance Health, and Employees in View are now equal summary cards.
- Cards are one row on desktop, two columns on medium screens, and one column on mobile.
- Analytics calculations, filters, tables, and routes were not changed.

## Workforce Policy Center

- Removed the duplicate title/description/action panel.
- Changed the large navigation cards into compact section tabs.
- Reorganized the Current Work Policy information into a consistent six-card grid.
- Made the guided setup steps compact.
- Replaced the long Review Changes sentences with:
  - policy metadata cards;
  - a readable weekly schedule table;
  - separate Attendance Rules and Overtime Rules summaries;
  - a clear assignment note;
  - a single bottom action bar.
- Policy lifecycle, assignments, calculations, and routes were not changed.

## Demo Attendance and Overtime

- Added `seeds/seed_august_2026_demo.php`.
- Adds or refreshes policy-calculated records from 2026-08-01 through 2026-08-04.
- Includes normal, late, early-departure, absent, incomplete, weekend/non-working-day, and overtime examples.
- Uses `AttendanceOperationService`; it does not manually write calculated overtime fields.
- Updates only rows marked with `August 2026 demo seed` and skips unrelated existing attendance.

## Holidays

- Added an idempotent 2026 holiday dataset in `seeds/data/holidays_2026.php`.
- Includes the published Myanmar public-holiday dates and keeps the two fictional company dates clearly marked as company holidays.
- Added `seeds/seed_2026_holidays.php` for holiday-only updates.
- Holiday-on-weekend precedence remains controlled by the existing resolver.

## Run the requested data updates on Windows

From the project root:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/apply_demo_updates_2026_08.ps1
```

The script requires the demo employees and Workforce Policy Center migrations to already exist. It does not change production data unless the project is deliberately configured to point at that database; use a local/demo database.
